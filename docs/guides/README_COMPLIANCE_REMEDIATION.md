# Збагачення постачальників і документи КАД

Підсумок фактичного запуску 09.10.2026: `data/compliance_remediation_20261009/REPORT_UK.md`.

## Перевірка джерел і локальне збагачення

```sh
.venv/bin/python src/supplier_enrichment.py
```

Читає основний архів тільки для читання. Перевіряє SHA-256 усіх сирих відповідей «Госзатрат», шукає дані постачальника в різних формах полів, створює `missing_suppliers.jsonl`, `enrichment_audit.json`, `raw_manifest.json`.

Локальні довідники: `data/imports/companies.csv` і `database/employers_2026-10-09.csv`. Точне нормалізоване зіставлення назв дає лише кандидатів з походженням. Скорочення правової форми, нечіткий пошук і автоматичне призначення ІПН не застосовуються. Неоднозначні збіги залишаються неоднозначними. Реєстровий статус, актуальність назви на дату контракту й санкційний статус не встановлюються цим зіставленням.

Відсутність знайдених справ, закінчення строку договору чи вибір переможця тендера не присвоюють статус виконання. Початковий архів не змінюється.

## Черга і рішення КАД

```sh
.venv/bin/python src/kad_documents.py
.venv/bin/python src/kad_documents.py --search --limit 5
.venv/bin/python src/kad_documents.py --collect --limit 47
```

Черга об'єднує 10 пілотних компаній, 4 компанії з окремого довідника, всіх юридичних осіб `data/imports/companies.csv` та довідника роботодавців, зі збереженням провідних нулів і перевіркою контрольних цифр. Філії з однаковим ІПН не є незалежними юридичними особами в цій черзі.

`--search` збирає першу сторінку для кожної доступної цілі; `first_page_collected` НЕ означає повноту справ за ІПН. Автоматичне збирання всіх наступних сторінок наразі не реалізоване. Пошук повертає метадані справ, а не PDF. `--collect` працює з 47 наявними справами і завантажує лише явно опубліковані PDF-посилання з доступного HTML карток. Якщо документи доступні тільки через динамічний інтерфейс, стан — `document_links_unavailable`, а не «рішень немає». При CAPTCHA, 401, 403, 429, 451 або 503 збір зупиняється; решта черги залишається pending. Інтервал між робочими запитами — 4 секунди. Файли стану зберігаються; повторний запуск не перестворює наявну чергу і не скидає її результати.

Авторизований маніфест документів має форму:

```json
[
  {
    "case_id": "Ідентифікатор справи з картки",
    "source_url": "Точний HTTPS URL опублікованого PDF на kad.arbitr.ru або ras.arbitr.ru",
    "local_file": "/absolute/path/to/already_downloaded_decision.pdf"
  }
]
```

`local_file` необов'язковий: за його відсутності виконується завантаження з `source_url`. URL повинен бути реальним і походити з картки/вивантаження; вигадані URL не приймаються як джерело.

```sh
.venv/bin/python src/kad_documents.py --manifest authorized_decisions.json
```

PDF і JSON з повним текстом сторінок зберігаються за SHA-256. Вирази знаходять згадки договорів, сум і процесуальних ролей із цитатою, контекстом і номером сторінки. Це кандидати для перевірки: сума держмита не стає сумою позову, відповідач не стає постачальником, згадка договору не стає встановленим порушенням. PDF без текстового шару позначаються `needs_ocr`; OCR автоматично не запускається.

Зміна `parsers/registry_sources.py` зберігає `supplier_name`, назви вкладених постачальників і `current_stage` як `source_execution_stage`, без автоматичного трактування статусу. Існуючий архів не перепарсовано і не перезаписано.

## Перевірки

```sh
PYTHONPATH=src .venv/bin/python -m unittest tests.test_compliance_remediation tests.test_sources -q
```

Перевірки охоплюють неоднозначні назви, контрольні цифри ІПН, походження відновлених даних, відсутність автоматичного присвоєння ІПН/статусів, CAPTCHA, сторонні перенаправлення, відхилення HTML замість PDF і збереження контексту сум та ролей.

## Тексти й мікробатч 20 компаній

```sh
.venv/bin/python src/supplier_text_extraction.py
PYTHONPATH=src .venv/bin/python -m pip install -r requirements/requirements_compliance_optional.txt
.venv/bin/python src/kad_microbatch.py
```

Новий звіт: `data/compliance_text_20261009/REPORT_UK.md`. Пошук явно позначених ІПН у сирих текстах із контекстом не призначає постачальників автоматично. Для цього запуску додаткові поля відсутні; знайдених ІПН — 0.

Мікробатч: п’ять названих користувачем компаній із наявними коректними ІПН і 15 додаткових юридичних осіб із локального довідника за санкційними позначками та match_method=inn. Він є комплаєнс-чергою. Використовується curl_cffi 0.13.0 з профілем Chrome, затримкою 5–10 секунд і підключенням до PDF-екстрактора. Після першого HTTP 451 решта 19 цілей залишена pending. Повторний запуск продовжить наявний файл, не перестворює список. Усі результати стосуються лише фактично виконаних запитів.

## Офіційні ІПН, браузерний КАД і офлайн-індекс

Результати нового запуску: `data/compliance_offline_20261009/`. `verified_tax_ids.json` містить три ІПН, підтверджені пошуком ФНС і PDF-виписками від 09.10.2026. Пошук за назвою ВНИИР-Прогресс повернув три різні юридичні особи; вони не об’єднані. КТРВ та УПКБ «Деталь» також зіставлені з локальним довідником роботодавців.

Браузерний доступ через Playwright-Stealth із Chromium у цьому середовищі успішно повертає пошукові результати КАД. Процес закриває службове повідомлення сайту, використовує його пошукову форму, перевіряє ІПН і зберігає фактично відправлені дати. Черга збирає перші сторінки 20 компаній; це не повне вивантаження всіх справ. CAPTCHA автоматично не розв’язується, проксі-ротація не налаштована.

Офлайн-архів `clearspending_local_snapshot.jsonl.gz` створено з уже наявного JSONL. Це не новий зовнішній дамп. Архів охоплює 65 897 записів початкових 10 тематичних запитів, не весь реєстр.

```sh
.venv/bin/python src/offline_contracts.py \
  --archive data/compliance_offline_20261009/clearspending_local_snapshot.jsonl.gz \
  --output data/my_new_offline_index
```

Модуль не використовує мережу. Він створює SQLite-індекс договорів і ролей ІПН, рахує записи та SHA-256 розпакованого потоку, виконує quick_check. Наявний індекс не перезаписується; для повторного запуску слід обрати нову папку результату. Поле execution_status залишається null.

Підсумок запуску від 09.10.2026: `data/compliance_offline_20261009/REPORT_UK.md`. Успішні всі 20 перших сторінок КАД (500 спостережень / 499 справ); судові PDF не отримано після прямих і браузерних спроб. Офлайн-індекс перевірено, новий зовнішній дамп не завантажено. 60 перевірок пройшли.
