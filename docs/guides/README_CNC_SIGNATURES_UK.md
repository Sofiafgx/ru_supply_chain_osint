# Технологічні сигнатури у публічних оголошеннях

Скрипт: `src/cnc_signatures.py`. ІПН за замовчуванням: `2128700223`,
`1804002498`, `6612001460`, `6444009038`.

```sh
.venv/bin/python src/cnc_signatures.py --output data/cnc_signatures/records.json
```

Залежності `httpx` і `beautifulsoup4` уже є в проєкті. Скрипт використовує
`src/cnc_trace_search.py` та модулі `parsers`; запускайте його з цього проєкту.

## Джерела і параметри

- `trudvsem`: офіційний API вакансій за ІПН із пагінацією.
- `hh`: офіційний API за ID роботодавця. Передайте перевірену відповідність
  через `--hh-employers employers.json`. Приклад структури:
  `{"2128700223": [{"employer_id": "123", "evidence_url": "https://example.org/verified-employer-identity"}]}`.
  Це синтетична структура; замініть ID і посилання реальними доказами.
  Скрипт вважає цю відповідність підтвердженим вхідним даним, зберігає її у
  звіті, але не перевіряє вміст evidence_url. Без відповідності етап HH
  повідомляє помилку і продовжує інші джерела.
- `rostender`, `joblab`, `cznelb`: часткове виявлення URL через Bing RSS
  за ІПН, потім читання окремих карток. RSS — допоміжний пошуковий індекс,
  не офіційний API цих порталів; доступність і повнота не гарантовані.
  Можна передати прямі URL через `--seeds seeds.json`:

```json
{
  "joblab": {"2128700223": []},
  "cznelb": {"2128700223": []},
  "rostender": {"2128700223": []}
}
```

Заповніть масиви посиланнями на окремі оголошення. Непорожній масив замінює
пошукове виявлення для відповідної компанії та джерела.
ІПН має бути явно вказаний у розпізнаному блоці роботодавця/замовника.
ІПН у підвалі, рекомендаціях або пошуковій видачі не є підтвердженням.
Якщо блок прихований або верстка відрізняється, скрипт відхиляє картку й
записує причину. Актуальна сумісність усіх живих сайтів не підтверджена:
читання Joblab через інструмент веб-перегляду повернуло 403,
головна сторінка CZNELB була доступна; прямий HTTP-доступ до РосТендер
у попередній перевірці завершився тайм-аутом.

```sh
.venv/bin/python src/cnc_signatures.py \
  --hh-employers employers.json \
  --seeds seeds.json \
  --export-control export_control.json \
  --output data/cnc_signatures/records.json
```

`--sources hh trudvsem rostender joblab cznelb` обмежує перелік джерел.
`--max-pages 10`, `--delay 1`, `--timeout 25` керують запитами.
Картки з CAPTCHA не вважаються оголошеннями; обходу авторизації немає.

## Записи

Один запис — одна згадка бренду/моделі в реченні. Підтримуються всі десять
заданих брендів, кириличні варіанти, моделі відомих сімейств, Siemens 840D,
категорії «токарный ЧПУ», «5-осевой», «обрабатывающий центр».
У категорії без бренду `cnc_brand` і `cnc_model` дорівнюють `null`.
Невідомі моделі не вигадуються. Для відбору потрібний верстатний/ЧПУ-контекст
у назві чи описі; випадкова згадка Siemens без такого контексту відхиляється.
Тендери відбираються за ремонтом/сервісом/обслуговуванням; оголошення про
постачання відхиляються. Вакансії не обмежуються лише операторами:
інженерні й технологічні посади також можуть містити сигнатури.

Приклад нижче синтетичний, не знайдена вакансія:

```json
{
  "company_inn": "2128700223",
  "source_site": "joblab.ru",
  "record_id": "123",
  "record_date": "2026-10-10",
  "text_fragment": "Работа на Haas VF-3; наладка ЧПУ.",
  "cnc_brand": "Haas",
  "cnc_model": "VF-3",
  "source_url": "https://joblab.ru/vacancy/123",
  "is_sanctioned_equipment": null,
  "equipment_categories": [],
  "export_control_basis": null
}
```

`text_fragment` — вихідне речення у видимому тексті після декодування HTML;
пунктуація, внутрішні пробіли й крапки з комою зберігаються. Пункти переліку
та абзаци без крапки повертаються цілими фрагментами. Розбиття regex є
евристикою: скорочення на кшталт «т.д.» можуть розбивати речення.
Немає перекладу або переказу. HTML-відповіді зберігаються як первинні знімки.

Дата публікації невідома — `null`. Якщо нативного ID немає, використовується
явно позначений `url_sha256:...`. Час запуску UTC зберігається у звіті.
Додаткові поля `equipment_categories` та `export_control_basis` дозволяють
перевірити категорію та підставу автоматичного прапорця.

## Зовнішній довідник експортного контролю

Без `--export-control` усі прапорці дорівнюють `null`. Файл — JSON-масив.
Правило містить:

- `rule_id`: унікальний ID;
- `brand`: канонічна назва бренду;
- `model_regex`: регулярний вираз для **цілої** моделі (`re.fullmatch`);
- `jurisdiction`: `EU` або `US`;
- `basis_url`: посилання на перевірену підставу;
- `checked_at`: дата перевірки у форматі ISO;
- `is_sanctioned_equipment`: логічне значення;
- необов'язковий `ambiguous`: `true`, якщо правило потребує уточнення;
- необов'язковий `equipment_category`: `cnc_lathe`, `five_axis` або
  `machining_center`; має бути прямо виявлена в тому самому реченні.

`true` повертається лише за **одним** відповідним правилом із позитивним
статусом і без `ambiguous: true`. Якщо моделі немає, правила немає,
є кілька відповідних правил або правило неоднозначне — `null`.
Навіть негативне правило дає `null`, а не юридичне твердження про відсутність
контролю. Скрипт не складає санкційного довідника за походженням брендів.
Необхідні для застосування правила характеристики та умови операції мають
бути перевірені під час підготовки довідника; сам текст вакансії їх часто не містить.
Прапорець є результатом скринінгу за переданим довідником.

## Збережені оголошення та перевірка

```sh
.venv/bin/python src/cnc_signatures.py --offline notices.json --output data/cnc_signatures/offline.json
PYTHONPATH=src .venv/bin/python -m unittest discover -s tests -p 'test_cnc*.py' -v
```

`notices.json` — масив із `source_site` (ключ або домен джерела),
`company_inn` або `company_tax_id`, `title`, `description`, `source_url`,
необов'язковими `record_id`, `record_date` або `posting_date`.
У режимі offline відповідність ІПН є підтвердженим вхідним даним;
мережевих запитів немає. `description` може містити оригінальний HTML.

Поруч із результатом зберігаються `.report.json` і каталог `_raw`.
Код завершення `2` означає помилку одного з етапів; результат може бути частковим.
Повторний запуск замінює JSON. Порожня вибірка не доводить відсутності
обладнання. Згадка у вимогах до кандидата не доводить володіння верстатом.

https://api.hh.ru/openapi/redoc
