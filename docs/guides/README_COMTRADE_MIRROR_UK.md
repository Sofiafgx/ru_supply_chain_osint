# Помісячна дзеркальна статистика UN Comtrade

`src/comtrade_mirror_async.py` асинхронно збирає офіційно заявлений експорт (`X`)
та реекспорт (`RX`) Китаю (156), Туреччини (792), ОАЕ (784), Казахстану (398),
Вірменії (51) та Сербії (688) до Російської Федерації (643).
HS6: 854231, 854232, 854233, 854239, 852691, 845710, 845811, 845961.

## Запуск

Python 3.10+ на macOS/Linux, залежність `httpx` уже є в `requirements.txt`:

```sh
python3 -m pip install 'httpx>=0.27'
python3 src/comtrade_mirror_async.py
```

Результат — `data/processed/trade/monthly_trade_mirror.jsonl` у поточній директорії.
Кожен рядок — один місячний підсумок країни × HS6 × потоку.
`data/processed/trade/monthly_trade_mirror.coverage.json` містить стан кожного запиту та обмеження
покриття. `state/.comtrade_mirror.sqlite3` зберігає успішні відповіді, порожні
відповіді, використаний бюджет запитів і час завершення паузи API.

За замовчуванням запитуються місяці від січня 2024 до грудня 2026.
Майбутні місяці, визначені за календарем Europe/Kyiv, пропускаються та
перераховуються у звіті. Поточний місяць може бути неповним або ще не опублікованим.

Приклад короткої перевірки:

```sh
python3 src/comtrade_mirror_async.py --start 2024-01 --end 2024-02 \
  --reporters 156 --hs-codes 854231 \
  --output data/comtrade_smoke/monthly_trade_mirror.jsonl \
  --state data/comtrade_smoke/cache.sqlite3
```

## Ліміти, розбиття запитів і продовження

Наданий шлях `/C/A/HS` означає **річну** частоту. Скрипт використовує
`https://comtradeapi.un.org/public/v1/preview/C/M/HS` із `period=YYYYMM`.
Кожен запит містить один місяць, одну країну, один HS6 і `flowCode=X,RX`.
`partner2Code=0`, `motCode=0`, `customsCode=C00`, `breakdownMode=classic`
вибирають підсумки без подвійного рахування за додатковими вимірами.

Preview повертає максимум 500 записів і не має документованої пагінації
через `page`, `offset` чи курсор. Скрипт не вигадує ці параметри: якщо
отримано 500 записів, він ділить запит на окремі потоки `X` та `RX`.
Якщо найменший запит також досягає 500 записів або `count` свідчить про
обрізання, такий запит отримує статус `error`; відповідь не приймається
за повну. Для такого випадку потрібен офіційний Download/Bulk API.
Суперечливі дублікати місячних підсумків також відхиляються.

Глобальний обмежувач запусків запитів спільний для всіх асинхронних працівників:
за замовчуванням 1 запит/секунду, 3 працівники, 5 повторів після першої спроби.
HTTP 429, 500, 502, 503, 504 та мережеві помилки викликають повтори з
експоненційною затримкою та випадковою добавкою. `Retry-After` підтримує
секунди та HTTP-дату. Пауза поширюється на всі працівники й зберігається
у стані. Якщо API просить чекати понад 60 секунд, запуск завершується
з частковим результатом; повторний запуск можливий після зазначеного часу.

`--daily-budget 500` — консервативний **локальний** бюджет за добу UTC,
а не твердження про гарантовану квоту анонімного Preview API.
Він враховує повтори й зберігається між запусками. Інші клієнти/API-ключі
можуть споживати зовнішню квоту незалежно від цього стану.
Після вичерпання бюджету повторіть ту саму команду наступної доби:
завершені запити будуть прочитані з кешу, незавершені — запитані знову.
Повні 36 місяців потребують 1728 базових запитів; за бюджету 500 це
щонайменше чотири доби, якщо всі місяці вже настали.

Не запускайте паралельно кілька копій із різними файлами стану:
їхні обмежувачі швидкості незалежні. Для спільного файла стану скрипт
сам блокує другий запуск. Після аварійного переривання кеш зберігається;
JSONL і звіт будуються при наступному завершеному запуску.

Код завершення `0`: усі придатні за датою запити виконані, включно з порожніми.
Код `2`: є помилки/відкладені запити; збережено частковий результат і звіт.
`queries_complete=true` не гарантує, що всі країни вже опублікували дані.
`no_data` означає відсутність рядків у відповіді, **не нульову торгівлю**.
`returned_flows` показує, які потоки повернуто; відсутній `RX` не підміняється нулем.

Для оновлення опублікованих із затримкою або переглянутих даних:

```sh
python3 src/comtrade_mirror_async.py --start 2026-09 --end 2026-12 --refresh
```

`--refresh` ігнорує кеш відповідей для вибраного діапазону, включно з порожніми,
але зберігає лічильник квоти. Кожен запуск перезаписує JSONL даними лише
вибраного діапазону: для повного експорту з кешу повторіть базову команду.
Збій оновлення не використовує старий кеш як успішно оновлені дані.

## Поля та інтервали

Обов'язкові поля: `period` (YYYY-MM), `reporter_code`, `reporter_name`,
`hs_code`, `flow_code`, `net_weight_kg`, `trade_value_usd`, `quantity`.
Вартість береться з `primaryValue`, резервне поле — `fobvalue`.
Відсутні числові значення залишаються `null`; явний нуль зберігається.
`quantity_unit_code` та `quantity_unit` потрібні, бо кількість не завжди
означає штуки. Збережено класифікацію та прапорці оцінювання кількості/ваги.

Для кожної групи країна × HS6 × потік місяці з `trade_value_usd > 100000`
позначаються `large_monthly_total=true`. Поля:

- `previous_large_period`: попередній спостережений місяць понад поріг;
- `delta_t_months`: різниця календарних місяців;
- `delta_t_days`: різниця між **першими днями** цих місяців;
- `interval_basis`: `observed_monthly_totals_not_shipments`.

Для першого такого місяця та місяців нижче/на порозі інтервали — `null`.
Поріг можна змінити через `--threshold`.
Наприклад, січень → березень 2024 дає 2 місяці та 60 календарних днів.

Це інтервал між місяцями з великими **сумарними обсягами**, а не між
окремими партіями. У Comtrade немає дат відвантажень, контрагентів чи
ідентифікаторів каналів. Місячні $150 000 можуть складатися з багатьох
малих партій. Прогалини в публікаціях або зборі можуть приховати
проміжні місяці понад поріг: оцінюйте Δt разом зі звітом покриття.
Експорт і реекспорт аналізуються окремо: їх не слід автоматично складати.
Самі ці дані не доводять обхід санкцій або кінцеве використання компонентів.
