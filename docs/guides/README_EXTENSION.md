# Додаткове охоплення джерел

Під час продовження збору 08.10.2026 отримано 47 унікальних справ КАД:
20 за ІПН 5408105577, 6 за 1650166051, 21 за 5835109448. Період реєстрації:
01.01.2022–08.10.2026. За кожним із цих трьох запитів збережено всі показані
результати. Ролі компаній можуть включати третіх осіб; пошук за ІПН не означає,
що компанія обов'язково є позивачем або відповідачем.

Знімки отримано з видимого DOM Chrome і перенесено у структуровані файли.
Довгі назви та пробіли нормалізовано; первинних HTTP-відповідей пошуку ці знімки
не замінюють. Рядки, контрольні суми і параметри пошуку збережені в
`data/extension_20261008/`, а записи та докази також об'єднано з основним архівом.

Основні файли:

- `data/collection_20261008/exports/kad.csv` — справи, дати, судді, суди, сторони, посилання.
- `data/collection_20261008/exports/kad.jsonl` — записи з походженням.
- `data/collection_20261008/source_coverage.json` — стан усіх восьми джерел.
- `data/extension_20261008/targets.json` — пріоритетні кандидати з наявних контрактів для наступної перевірки. Ключові слова і товарні коди не підтверджують кінцеве застосування товарів.

У Chrome відкриті форми входу ImportGenius, Panjiva та 52wmb. Для продовження
потрібна авторизація в акаунті з доступом до потрібних даних або власні
CSV/JSON-вивантаження. Паролі та ключі не потрібно надсилати в чат.
Checko використовує `CHECKO_API_KEY` у локальному `.env`;
на момент перевірки ключа немає, а публічний сайт не відповідає.
ЄІС не відповідає через поточне з'єднання; його адаптер приймає власні XML/JSON/CSV
вивантаження. `OSINT_PROXY` у `.env` дозволяє використовувати один власний доступний
мережевий маршрут. Локальні перевірки та питання авторизації не означають,
що даних на сайтах немає.

Для імпорту підготовлено `src/coverage_extension.py`, який зберігає вхідні байти,
SHA-256, джерело, параметри вибірки та нормалізовані записи. Змінений вхідний файл
має новий ідентифікатор завдання. Порожній документ, закритий доступ або
невідповідність заявленої кількості не позначаються успішним збором.

Приклад імпорту наданого вивантаження:

```sh
.venv/bin/python src/coverage_extension.py --source importgenius --input incoming/importgenius.csv --url https://app.importgenius.com/
```

Для фактичного TTS потрібні залишок матеріалу і добове споживання в однакових
одиницях, дата актуальності та джерело обох величин.
`examples/inventory_for_tts.csv` — порожній шаблон цих даних.
Розрахунок виконує `estimate_tts(stock_units, daily_consumption_units)`;
за відсутності вхідних величин результат не створюється.
Інтервали між поставками можна обчислити з митної історії з точним ІПН,
але вони не встановлюють поточних залишків.
