# Допоміжні та історичні утиліти

`audit/` — датований аудит робочої папки. `historical/` — збережені одноразові утиліти для вже виконаних зборів; вони не входять до регулярного конвеєра й можуть залежати від старого браузерного оточення.

Запуск за потреби: `.venv/bin/python main.py tools/audit/audit_workspace_20261009.py`. Історичні утиліти пишуть до початкових датованих папок; повторний запуск може оновити старі звіти.
