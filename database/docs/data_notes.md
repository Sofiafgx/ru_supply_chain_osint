# Особенности данных

Что нужно знать, чтобы не ошибиться в запросах и выводах. Источник всех данных сейчас — портал ГУР «War & Sanctions».

## Идентификаторы

- **Филиалы делят ИНН и ОГРН головной компании.** 19 ИНН принадлежат 64 компаниям: например, ПАТ «ОАК» и пять его филиалов (ЛАЗ, КнААЗ, НАЗ, ОКБ Сухого, ОТА). Группировка по ИНН склеит их — для подсчёта предприятий используйте `company_id`.
- **Ошибки ввода номеров на портале исправлены** для российских компаний (57 записей): ИНН и ОГРН перепутаны местами; оба номера в поле ИНН через запятую; потерянный ведущий ноль ИНН (регионы 01–09, восстанавливается по коду региона в ОГРН). Оригиналы — в `inn_raw`, `ogrn_raw`.
- **Остались некорректные номера** примерно у 20 записей со страной РФ: часть — иностранные фирмы, ошибочно помеченные на портале как российские (например, KIRA INTERNATIONAL TRADE CO LIMITED), часть — опечатки. По ИНН в ЕГРЮЛ они не найдутся.
- **У иностранных компаний** в `inn`/`ogrn` лежат местные регистрационные номера в произвольном формате (`DMCC-786039`, `91320206MADCRUHRXC`). ИНН есть только у ~30% иностранных компаний.
- **Без ИНН** 1949 компаний (включая заглушку), из них 212 со страной РФ.

## Санкции Украины

Профили раздела «Санкційні списки партнерів → Юридичні особи» показывают **8 юрисдикций без Украины**. Поэтому строка `jurisdiction = 'UA'` есть только у 1327 компаний (у тех, что есть и в разделах ВПК).

- Нет строки UA → **неизвестно**, а не «санкций нет».
- Проверка «под санкциями Украины» корректна: `EXISTS (... jurisdiction = 'UA' AND is_sanctioned)`.
- Проверка «не под санкциями Украины» по отсутствию строки — некорректна.
- `sanctions_count_intl` (без UA) сопоставим между всеми компаниями; `sanctions_count` (с UA) — нет.

## Иерархия Ростеха

Две версии родителя хранятся в `company_edge` с разным `source`:

- `rostec_tree` — дерево на странице /rostec (одно ребро «компания → прямой родитель»);
- `profile` — цепочка «В структурі Ростех» в профиле (рёбра между соседними звеньями).

Они **расходятся у 76 компаний**: дерево и цепочка профиля называют разных прямых родителей (например, у 16324 в дереве родитель 16291, а в цепочке — 6803). Какая версия верна, не проверено; для обходов дерева выбирайте один `source` явно.

## Покрытие профилей

- **Полные профили** (адрес, описание, ссылки, связи) — в основном у компаний ВПК: Ростех, производители БпЛА, заводы. У 6000+ санкционных юрлиц профиль из 4 полей: название, ИНН, рег. номер, страна (+ санкции).
- Адрес — 17,6% компаний, описание — 17,3%, краткое название — 24,5%.
- `region` и `city` пока пусты: адрес не разобран.
- `website` — эвристика (первая ссылка не с агрегатора, СМИ, архива или соцсети). Холдинговые сайты допустимы: один сайт может стоять у нескольких дочерних компаний. Это не «официальный сайт» без проверки.

## Оборудование

- **Счётчики портала — это экземпляры, а не карточки.** «Верстатів 1655» = `SUM(quantity)`; карточек (`tool`) 1567.
- **Пустые на портале поля** в схему не заведены: «Модель/Маркування», «Стислий опис», «Роки виробництва» — 0 из 1567. Модель обычно указана в `name_*`.
- `name_uk = 'Не ідентифіковано'` у 98 станков: производитель известен, модель — нет.
- **`evidence_type` выведен загрузчиком** по ссылкам и полям (лизинг → `fedresurs.ru` или срок лизинга; закупка → `zakupki.gov.ru`, `clearspending.ru`; видео → встроенное видео или YouTube/Rutube/VK/Дзен/Google Drive). Это приближение фильтра портала «Тип доказів», а не его значение.
- **Нестандартные даты доказательств** (14 шт.: «2014-2015», «06.2023», «03.05 2022», «-») — `published_on` NULL, исходник в `published_raw`.
- Документы (`tool_document.url`) — ссылки на скачивание с портала; файлы не загружены.

## Модели БпЛА

- **6 флагманских моделей** (Оріон, Ланцет, Скальпель, Клин, Князь Олег, V2U) на портале — отдельные лендинги без числового id: у них заполнен `slug`, нет `url_ru/url_en` и характеристик.
- На портале написано «215 БПЛА», найдено 209 (203 + 6) — ссылок на остальные нигде нет.
- Значения характеристик — свободный текст с единицами («до 60 км/год», «5-15 км», «up to 2.5 kg»); для числовых сравнений их нужно разбирать.
- Ключ характеристики — английская подпись: близкие по смыслу характеристики могут быть под разными ключами (`speed` и `maximum_speed`, `payload` и `target_load_weight_max`).

## Заглушки

Компания, на которую есть ссылка, но которой нет ни в одном разделе, создаётся с одним названием (`gur_id` и `name_full_uk`). Сейчас это `gur_id = 15111` — правопреемник «ФІЛІЯ "ЗІД" АТ "НПО "КУРГАНПРИБОР" М. ПЕРМ».

## Страны

`country` объединяет страны регистрации компаний (114) и страны производителей станков (34, у них есть `gur_country_id`); всего 117. Названия — как на портале: «російська федерація» с маленькой буквы, «ТОТ України» (временно оккупированные территории) — отдельная страна. У 50 компаний страна не указана.

## Атлас ВПК коллеги

`other_vacancies/vpk-structured.json` — атлас предприятий ВПК от другого участника (05.10.2026): 767 карточек Ростеха из ГУР, 80 записей из непроверенного MD-обзора, банки и контрагенты. Компании, иерархия и банки в нём — подмножество нашей загрузки ГУР, поэтому взяты только:

- **38 связей «поставщик → заказчик»** (`company_edge.kind = 'supplier'`). Атлас выписал их вручную из `description_uk` профилей ГУР; каждая сверена с текстом профиля. Это выборка, а не полный перечень кооперации: остальные такие строки в описаниях ещё не разобраны. Объём, цена и доля поставок неизвестны; связь не означает единственного поставщика.
- **8 финансовых показателей** (`company_financial`): заявления Ростеха и пересказ отчётности ОДК в СМИ.

Сопоставление с нашими компаниями: по `gur_id`, для записей обзора — по ИНН (должен найтись ровно один), для 5 контрагентов без ИНН — по названию (`COUNTERPARTY_GUR_IDS` в загрузчике). Если запись не находится или находится несколько раз, загрузка падает.

## Чего нет в ГУР

ОКВЭД, вакансии, контакты, численность, финансы — добирать из ЕГРЮЛ, hh.ru, Trudvsem и агрегаторов по ИНН. Ребра «компания поставляет продукт» из текста `description_*` (38 уже есть из атласа, см. выше) и регион/город из адреса — этап LLM-разбора.
