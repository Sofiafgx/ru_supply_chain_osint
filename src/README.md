# Код проєкту

Запускайте модулі через `main.py` із кореня. `main.py --list` показує доступні файли. [Карта модулів за темами](../docs/PROJECT_MAP_UK.md).

- `parsers/` — розбір і доступ до джерел.
- `models/` — структури записів.
- `analytics/` — аналіз текстів та метрики з перевіркою входів.
- `osint_pipeline/` — конвеєр збору за маніфестом.
- Файли `*_cli.py` та інші модулі — запуск збору, експорту й перевірок.

Для імпорту з інтерактивного Python або запуску тестів додайте `src` до `PYTHONPATH`.
