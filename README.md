## Запуск

Команди нижче виконуються з кореня проєкту. `main.py` також можна викликати за абсолютним шляхом із іншої папки: він сам встановить робочу папку проєкту.

```sh
.venv/bin/python main.py --list
.venv/bin/python main.py collection_cli --help
.venv/bin/python main.py telegram_public_cli --help
.venv/bin/python main.py osint_pipeline --help
PYTHONPATH=src .venv/bin/python -m unittest discover -s tests
```

`main.py` без назви модуля відкриває CLI джерел. Старі команди виду `python collection_cli.py` тепер пишуться як `python main.py collection_cli` або `python src/collection_cli.py` з кореня. Для `python -m osint_pipeline` потрібен `PYTHONPATH=src`.

Секрети зберігаються в `.env`; приватний перелік проксі — у `config/private/proxies.txt`. Не додавайте їх до публічних матеріалів.

[Журнал упорядкування 10.10.2026](reports/maintenance/REORGANIZATION_UK_20261010.md) містить причини видалення та карту старих і нових шляхів. Історичні знімки збережені без переписування доказів.
